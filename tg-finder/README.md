# tg-finder — поиск Telegram-чатов по критериям

Бот ищет **группы и каналы** по ключевым словам, проверяет число участников и права
на отправку сообщений и присылает тебе ссылки на вступление. Только для владельца
(`FINDER_ADMIN_ID`).

Почему нужен user-аккаунт: Bot API не умеет глобальный поиск чатов. Поиск идёт
через MTProto (библиотека **Telethon**) твоим аккаунтом — поэтому один раз нужно
войти кодом из Telegram. После этого сессия лежит в файле и бот работает сам.

## Что умеет

* поиск по нескольким ключевым словам (через запятую);
* фильтр по числу участников — минимум и максимум;
* тип: `group` (чаты), `channel` (каналы), `any`;
* **только там, где можно писать** — проверяется `banned_rights.send_messages`
  и заявка на вступление (`join_request`), read-only чаты и каналы отсекаются;
* только публичные чаты с юзернеймом (ссылка `t.me/username` всегда рабочая);
* исключения по словам в названии/описании;
* лимит результатов за прогон;
* дедупликация в SQLite: повторно те же чаты не приходят;
* кнопки: критерии, поиск, последние, CSV, очистка, стоп.

## Установка в Termux

```bash
pip install -r requirements.txt
cp .env.example .env
nano .env
```

В `.env` нужно:

1. `FINDER_BOT_TOKEN` — новый бот у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. `FINDER_ADMIN_ID` — твой id (например, из [@userinfobot](https://t.me/userinfobot)).
3. `TG_API_ID`, `TG_API_HASH` — [my.telegram.org](https://my.telegram.org) →
   **API development tools** → создать приложение. Это не токен, а пара чисел/строк.
4. `TG_PHONE` — номер аккаунта, которым будешь искать.

## Один раз войти

```bash
python login.py
```

Спросит код из Telegram (и пароль 2FA, если включён). Рядом появится
`finder_session.session` — боту больше вход не нужен, код не спрашивает.

## Запуск

```bash
termux-wake-lock
nohup python bot.py > finder_run.log 2>&1 &
tail -f finder.log
```

Остановить: `pkill -f "python bot.py"`.

## В боте

1. **⚙️ Критерии** → ключевые слова, диапазон участников, тип, тумблеры.
2. **🔍 Искать** — бот идёт по каждому слову, дёргает полную инфу и присылает
   ссылки пачками.
3. **📋 Последние** / **📤 CSV** — выгрузка всего, что уже в базе.

Пример хороших критериев для рекламы:

```
Ключевые слова: крипта, инвестиции, бизнес
Исключить: скам, казино, вакансии
Участники: 1000-50000
Тип: group
Только где можно писать: да
Только с юзернеймом: да
Результатов: 40
```

## Ограничения, о которых надо знать

* **Лимит поиска.** Telegram отдаёт максимум ~100 результатов на запрос и режет
  частые обращения (`FloodWaitError`) — бот спит столько, сколько скажет сервер.
  Поэтому «все чаты, которые есть» — это все, что отдаёт поиск, а не абсолют.
* **Не все группы найдутся.** Поиск индексирует названия/юзернеймы и сообщения;
  закрытые группы без юзернейма не находятся в принципе.
* **Право писать ≠ отсутствие модерации.** Бот проверяет техническую возможность
  отправки, но правила чата могут запрещать рекламу — за бан отвечает аккаунт.
* **Спам-риск.** Массовая рассылка ссылок с одного аккаунта быстро ведёт к
  ограничениям Telegram. Разные чаты, паузы, свои формулировки.
* Парсинг и рассылка рекламы нарушают правила многих чатов: это твой аккаунт и
  твои последствия.

## Файлы

```
tg-finder/
├── bot.py          # aiogram: меню, критерии, поиск, CSV
├── finder.py       # Telethon: поиск + проверка прав и участников
├── login.py        # одноразовый вход в аккаунт
├── db.py           # SQLite: чаты, критерии, прогоны
├── config.py
├── requirements.txt
└── .env.example
```
