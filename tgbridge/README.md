# tgbridge — бот-переходник на Telegram-канал

Отдельный бот: приводит людей в канал, проверяет подписку и выдаёт контент.
Управление — только у владельца, внутри бота.

## Что умеет

**Для людей**
1. `/start` → приветствие + кнопка «📢 Перейти в канал».
2. «✅ Я подписался» → бот проверяет через `get_chat_member` → выдаёт контент.
3. Не подписан — вежливый алерт, ничего не выдаёт.

**Для тебя (ADMIN_ID)**
| Кнопка | Что делает |
|---|---|
| 📊 Статистика | всего запустило, новые за сутки/неделю, активные за 24 ч, подписались, конверсия, график по дням |
| 👥 Последние | 10 последних запусков с id и отметкой подписки |
| 📢 Канал | id канала + ссылка (`-1001234567890\|https://t.me/имя`) |
| ✍️ Приветствие | текст первого экрана |
| 🎁 Контент | что выдаётся после подписки |
| 📨 Рассылка | всем пользователям, с отчётом «доставлено / не дошло» |
| 📤 Экспорт CSV | файл со всеми пользователями |

Счётчик «сколько человек запустило бота» — это `total` в статистике: уникальные
пользователи по `user_id`, повторные `/start` не считаются.

## Установка

```bash
cd ~/tiktok-telegram-bot/tgbridge
cp .env.example .env
nano .env       # BRIDGE_BOT_TOKEN и BRIDGE_ADMIN_ID
python bot.py
```

`.env`:

```bash
BRIDGE_BOT_TOKEN=123456789:AA...      # новый бот от @BotFather
BRIDGE_ADMIN_ID=8828367482
BRIDGE_CHANNEL_ID=-1001234567890      # можно пусто и задать в боте
BRIDGE_CHANNEL_URL=https://t.me/имя
```

## Канал

1. Создай канал, добавь бота **администратором** (иначе `get_chat_member` не сработает).
2. id канала: перешли любой пост из канала боту `@userinfobot` или возьми из ссылки вида `t.me/c/1234567890/...` → `-1001234567890`.
3. В боте: 👑 Админ-панель → 📢 Канал → пришли `-1001234567890|https://t.me/имя`.

## Данные

`bridge.db` (SQLite): `users`, `settings`, `events`. Лежит рядом с ботом,
в git не попадает. Экспорт — кнопкой, файл `export_users.csv`.

## Фоновый запуск

```bash
cd ~/tiktok-telegram-bot/tgbridge
setsid nohup python bot.py > bridge_run.log 2>&1 < /dev/null &
```
